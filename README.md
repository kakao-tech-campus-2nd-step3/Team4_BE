# 💪 LINKFIT 
## 서비스 개요
LINKFIT은 개인 맞춤형 PT(퍼스널 트레이닝) 서비스를 제공하는 플랫폼입니다. 많은 사람들이 헬스장과 트레이너에 대한 신뢰할 수 있는 정보를 찾기 어려워 효과적인 트레이닝을 계획하고 실천하는 데 어려움을 겪습니다. 기존에는 금액을 보고 PT를 결정해야 했지만, LINKFIT은 투명한 가격 정보와 더 넓어진 선택의 폭을 제공하여 사용자가 쉽게 선택할 수 있도록 돕습니다. 또한, 회원들은 발품을 팔지 않고도 다양한 트레이너들의 정보를 한 곳에서 확인하고 선택할 수 있어 더 나은 피트니스 경험을 지원합니다. 트레이너와의 실시간 채팅을 통해 빠르고 원활하게 소통할 수 있어, 사용자들이 더욱 편리하게 서비스 이용할 수 있습니다.

## 주요 기능
- 선호도 등록에 따른 맞춤형 트레이너 제안: 사용자가 등록한 선호도를 바탕으로 가장 적합한 트레이너를 추천해줍니다.
- 역제안 서비스: 기존의 PT 서비스와는 달리, 사용자가 트레이너에게 PT 제안을 받고 그 중에서 자신에게 맞는 트레이너를 선택할 수 있는 기능입니다.
- 채팅 기능: 트레이너와 회원 간의 빠르고 원활한 소통을 위한 실시간 채팅 기능을 제공합니다.
- 리뷰 기능: 사용자들이 트레이너에 대해 리뷰를 남겨 신뢰도를 높이고, 다른 사용자들이 더 나은 선택을 할 수 있도록 돕습니다.
- 스케줄 관리 기능 : 사용자가 PT 세션을 쉽게 관리하고 예약할 수 있도록 돕는 스케줄 관리 기능을 제공합니다.
