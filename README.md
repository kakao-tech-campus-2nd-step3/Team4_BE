<!-- 서비스 개요 -->
<div id="서비스-개요" style="border: 2px solid #ddd; border-radius: 10px; padding: 20px; margin: 20px 0;">
  <h2>🚀 서비스 개요</h2>
  <p>
    LINKFIT은 <strong>개인 맞춤형 PT(퍼스널 트레이닝)</strong> 서비스를 제공하는 플랫폼입니다.
    많은 사람들이 헬스장과 트레이너에 대한 신뢰할 수 있는 정보를 찾기 어려워 효과적인 트레이닝을 계획하고 실천하는 데 어려움을 겪습니다.
    기존에는 금액을 보고 PT를 결정해야 했지만, LINKFIT은 <strong>투명한 가격 정보</strong>와 더 넓어진 선택의 폭을 제공하여 사용자가 쉽게 선택할 수 있도록 돕습니다.
  </p>
</div>

<!-- 주요 기능 -->
<div id="주요-기능" style="border: 2px solid #ddd; border-radius: 10px; padding: 20px; margin: 20px 0;">
  <h2>✨ 주요 기능</h2>
  <h4>1️⃣ <strong>선호도 등록에 따른 맞춤형 트레이너 제안</strong>: 사용자가 등록한 선호도를 바탕으로 가장 적합한 트레이너를 추천해줍니다.</h4>
  <h4>2️⃣ <strong>역제안 서비스</strong>: 기존의 PT 서비스와는 달리, 사용자가 트레이너에게 PT 제안을 받고 그 중에서 자신에게 맞는 트레이너를 선택할 수 있는 기능입니다.</h4>
  <h4>3️⃣ <strong>채팅 기능</strong>: 트레이너와 회원 간의 빠르고 원활한 소통을 위한 실시간 채팅 기능을 제공합니다.</h4>
  <h4>4️⃣ <strong>리뷰 기능</strong>: 사용자들이 트레이너에 대해 리뷰를 남겨 신뢰도를 높이고, 다른 사용자들이 더 나은 선택을 할 수 있도록 돕습니다.</h4>
  <h4>5️⃣ <strong>스케줄 관리 기능</strong>: 사용자가 PT 세션을 쉽게 관리하고 예약할 수 있도록 돕는 스케줄 관리 기능을 제공합니다.</h4>
</div>
